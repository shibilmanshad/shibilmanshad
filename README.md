# Hi, I'm Shibil Manshad K 👋

### Data Analyst · AI Builder · Automation & Cloud

📊 Data Analytics &nbsp;·&nbsp; 🐍 Python &nbsp;·&nbsp; 🗄️ SQL &nbsp;·&nbsp; 📈 Power BI &nbsp;·&nbsp; 🤖 AI / LLMs &nbsp;·&nbsp; ☁️ Azure / AWS &nbsp;·&nbsp; ⚙️ Automation & APIs

I turn business data into dashboards, reports and decisions, and I build AI-powered tools, computer vision systems and automation workflows around it.

My current interests sit at the intersection of data analytics, Python, generative AI (RAG and LLM apps), cloud services and API-driven automation. I'm an Artificial Intelligence and Data Science graduate based in Dubai, UAE.

## 🤖 What I Build

- 📈 **Dashboards and reporting:** interactive Power BI dashboards, KPI tracking and automated reports
- 🐍 **Python analytics:** data cleaning, transformation and exploratory analysis with Pandas, NumPy and SQL
- 🧠 **AI / LLM applications:** RAG pipelines, document intelligence and semantic search with LangChain, ChromaDB and local LLMs
- 📄 **Intelligent document processing:** OCR, information extraction, layout analysis and table extraction from PDFs, scans and spreadsheets
- 💬 **Natural language processing:** text classification, NER, summarization, question answering and embedding-based semantic search
- 👁️ **Computer vision:** real-time detection and monitoring with YOLOv8, OpenCV and CNNs
- ⚙️ **Automation and integration:** ETL pipelines, data validation, REST API integration and workflows that replace manual processes
- ☁️ **Cloud and MLOps:** Azure AI Services, AWS, Docker, MLflow and CI/CD with GitHub Actions
